# 🏙️ Города мира (СГР: Города)

Браузерная игра-поисковик слов. На квадратном поле спрятаны **3 города**. Задача — найти их, проводя пальцем/мышью от первой буквы к последней по прямой (горизонталь или вертикаль).

## 🚀 Запуск (GitHub Pages)

1. Запушьте в репозиторий 4 файла в корень:
2. **Settings → Pages → Deploy from a branch** → `main` / `/root`.
3. Через 1–2 минуты игра доступна по адресу `https://<username>.github.io/<repo>/`.

Локально можно открыть `index.html` напрямую — сборка не нужна. Если стили не грузятся — проверьте, что файл называется **ровно** `styles.css` (регистр важен).

## 🎮 Как играть

**Раунд = одно поле с 3 городами.**
- Нашёл **1 город** → кнопка **«Дальше»** становится активной → можно идти в следующий раунд (+100 очков).
- Остался и нашёл **2-й** → +100 (итого 200).
- Нашёл **3-й** → +100 (итого 300), раунд закрывается автоматически через 1.5 сек.
- Кнопка **«Подсказка»** — подсвечивает одно слово (3 подсказки на регион).
- Кнопка **«Заново»** — перезапуск текущего региона с подтверждением.

**Регион = 10 раундов.** Максимум очков за регион = 10 × 3 × 100 = **3000**.

## ⭐ Звёзды и переход между регионами

Звёзды считаются по доле очков от максимума региона:

| Звёзд | % от 3000 | Очков |
|-------|-----------|-------|
| ★☆☆☆☆ | 25% | 750 |
| ★★☆☆☆ | 45% | 1350 |
| ★★★☆☆ | 60% | **1800 — проходной балл** |
| ★★★★☆ | 75% | 2250 |
| ★★★★★ | 90% | 2700 |

- Для открытия следующего региона нужно **3★** в предыдущем.
- **5★** = регион «мастерён», реплей заблокирован.
- **Рекорд** сохраняется в `localStorage` для каждого региона отдельно и показывается в HUD и в оверлее.

## 🗺️ Карта мира

Кнопка **🗺** в HUD открывает интерактивную карту. Можно открыть в любой момент.

- 🟢 **зелёные** — 5★, регион пройден, реплей закрыт.
- 🟡 **золотые (пульсируют)** — текущий регион.
- 🔵 **бирюзовые** — доступны для игры (реплей для улучшения рекорда).
- ⚪ **серые** — закрыты, пока предыдущий не пройден на 3★.

Клик по недоступному региону → тост с подсказкой. Клик по доступному → зум-глобус → старт региона.

## ⚠️ Известные ограничения прототипа

- Все названия пишутся **слитно** (`НЬЮЙОРК`, `ЭРРИЯД`, `АДДИСАБЕБА`).
- Только **города** — страны и реки убраны по последнему ТЗ.
- На поле 6×6 могут не уместиться 3 длинных города — сработает fallback (2 или 1 слово). Если часто — расширим пул коротких названий.
- Переход между регионами — **эмодзи-глобус** (заглушка). Настоящая анимированная SVG-карта — в дорожной карте.
- Звуки — процедурные через Web Audio API.
- Пороги звёзд (25/45/60/75/90%) — **предварительные**, калибруются по тестам.
- Прогресс сохраняется только в `localStorage` браузера (нет сервера, нет аккаунтов).

## 🧪 Чек-лист тестирования

**Механика раунда:**
- [ ] 3 города показаны пилюлями над полем, по мере нахождения — гаснут с ✓.
- [ ] После 1-го найденного — кнопка «Дальше» активна.
- [ ] После 3-го — авто-переход через ~1.5 сек.
- [ ] Неверное слово → тряска клеток, сброс.
- [ ] Подсказка подсвечивает первое ненайденное слово.

**Уровни и звёзды:**
- [ ] 10 раундов на регион, прогресс-бар заполняется.
- [ ] Звёзды в HUD обновляются по ходу уровня.
- [ ] Оверлей по завершении: <3★ → «Повторить», ≥3★ → «Дальше» + «К карте».
- [ ] Рекорд сохраняется после реплея (HUD + оверлей «🎉 Новый рекорд!»).
- [ ] 5★-регион нельзя переиграть (тост с карты).

**Карта:**
- [ ] 🗺 открывается в любой момент.
- [ ] Текущий регион — золотой, пульсирует.
- [ ] Пройденные на 5★ — зелёные, клик → тост.
- [ ] Закрытые — серые, клик → тост.
- [ ] Переключение между открытыми регионами работает.

**Устройства:**
- [ ] Проведение пальцем на iOS Safari / Android Chrome.
- [ ] Поле центрировано, влезает в экран.
- [ ] Кнопки удобно нажимать большим пальцем.
- [ ] Нет случайных зумов и выделений.
- [ ] Ориентация экрана (портрет/ландшафт) не ломает верстку.

**Звук:**
- [ ] Включается после первого касания (iOS user-gesture).
- [ ] Различаются: выбор буквы, правильное слово, ошибка, подсказка, уровень пройден, авто-переход раунда.
