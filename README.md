# 🗺️ Страны, города и реки (СГР)

Прототип браузерной игры-поисковика слов. На квадратном поле спрятано название страны, города или реки. Игрок должен провести пальцем/мышью от первой буквы к последней и получить очки.

## 🚀 Запуск (GitHub Pages)

1. Запушьте файлы в репозиторий:
2. В настройках репозитория → **Settings → Pages**.
3. Source: **Deploy from a branch** → Branch: `main` / folder `/root`.
4. Через 1–2 минуты игра доступна по адресу `https://<username>.github.io/<repo>/`.

Локально можно открыть просто `index.html` в браузере — сборка не нужна.

## 🎮 Как играть

- Поле **15×15**, размер фиксирован.
- Потяните от первой буквы к последней по прямой (по горизонтали или вертикали).
- Правильное слово → **+100 очков**, поле обновляется.
- **3 подсказки** на уровень — подсвечивают слово.
- **Пропустить** — скипнуть слово (очки за него потеряны).
- **Заново** — перезапуск уровня с нуля.
- Для перехода дальше нужно **3 звезды из 5** (угадать ≥60% слов уровня).

## ⚠️ Известные ограничения прототипа

- Переход между уровнями — **эмодзи-глобус** (заглушка). Настоящая SVG-карта мира — следующий этап.
- Все названия пишутся **слитно**, без дефисов и пробелов (`НЬЮЙОРК`, `РОСТОВНАДОНУ`).
- Звуки — процедурные через Web Audio API. Заменим на ассеты в следующих версиях.
- Пул слов пока небольшой (20–40 на уровень), будет расширяться.
- Пороги звёзд (25/45/60/75/90%) — **предварительные**, калибруются по итогам тестирования.

## 🧪 Что проверить (чек-лист тестирования)

**Десктоп (Chrome / Firefox / Safari):**
- [ ] Поле центрировано, ячейки читаемы.
- [ ] Проведение мышью работает плавно.
- [ ] Правильное слово → вспышка + `+100` + новое поле.
- [ ] Неправильное → тряска клеток и сброс.
- [ ] Подсказка подсвечивает слово (3 раза).
- [ ] Пропустить — новое слово, очки не растут.
- [ ] Заново — сброс уровня после подтверждения.
- [ ] После всех слов → оверлей со звёздами.
- [ ] При ≥3 звёздах → «Дальше» → глобус → следующий уровень.
- [ ] При <3 звёздах → «Повторить».
- [ ] На 7-м уровне → финальный экран → «Играть заново».

**Мобильный (iOS Safari / Android Chrome):**
- [ ] Жест пальцем работает (не скроллит страницу).
- [ ] Поле влезает в экран без обрезки.
- [ ] Кнопки удобно нажимать большим пальцем.
- [ ] Нет случайных зумов / выделений.

**Звук:**
- [ ] Звук включается после первого касания (iOS требует user-gesture).
- [ ] Различаются: выбор буквы, правильное слово, ошибка, подсказка, уровень пройден.
